# StaySync Enterprise — Micro-Stay & P2P Booking Resale Engine
**Capstone Project (DBMS) | Department of Data Science**

## 📌 Overview
StaySync Enterprise is a 3NF Relational Database Ledger designed to eliminate non-refundable cancellation losses via Peer-to-Peer (P2P) reservation reselling and provide hourly micro-stay indexing for transit travellers.

## 🛠️ Key Features
- 3rd Normal Form (3NF) Compliance
- 8 Relational Entities with PK/FK Constraints
- Atomic Transaction Row Locking & Date Validation
- Universal SQL Engine Compatibility (MySQL / Oracle 10g+)
